Política de privacidad

Última actualización: 3 de octubre de 2026.

Responsable

RVM Serveis, Calle 27, número 207A, Catarroja (Valencia). Contacto: rvm.serveis@gmail.com o WhatsApp 651 770 682.

Qué datos tratamos y para qué

Podemos tratar el nombre, teléfono, correo electrónico, máquina solicitada, fechas y observaciones que facilites. Los usamos para atender consultas, gestionar solicitudes y reservas, coordinar la prestación del alquiler y mantener las comunicaciones relacionadas con ellas.

Base del tratamiento

Usamos los datos necesarios para responder a tu solicitud y gestionar los pasos previos o la reserva. La recepción de ofertas por notificación push es opcional: solo la activamos si marcas expresamente la casilla de ofertas y aceptas las notificaciones del navegador. Aceptar la información de privacidad no activa publicidad.

Notificaciones de ofertas

Si te suscribes, podremos enviarte hasta dos notificaciones push al mes con ofertas de alquiler. Puedes retirar el consentimiento en cualquier momento desde «Cancelar ofertas push» al pie de la web o bloqueando las notificaciones en la configuración del navegador. La retirada no afecta a la atención de una consulta o reserva.

Destinatarios y servicios

Los datos se procesan con los servicios técnicos necesarios para operar el sitio y gestionar sus formularios y reservas, incluido Supabase para la base de datos y las notificaciones, y FormSubmit para enviar las consultas y avisos por correo. Estos proveedores pueden tratar datos conforme a sus condiciones y medidas de protección.

Conservación

Conservaremos los datos durante el tiempo necesario para atender la consulta o gestionar la reserva y, posteriormente, durante los plazos legales aplicables. Los datos usados para ofertas push se conservarán para esa finalidad hasta que retires el consentimiento; al cancelar la suscripción se desactiva y elimina la suscripción de notificaciones.

Tus derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad, y retirar el consentimiento cuando el tratamiento se base en él, escribiendo a rvm.serveis@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos en aepd.es.

Seguridad

Aplicamos controles técnicos y organizativos para proteger los datos y limitar el acceso a las funciones administrativas. No envíes por los formularios información especialmente sensible.

Esta información describe los tratamientos de este sitio. Para ejercer un derecho o resolver una duda, escríbenos al correo indicado.
